LoginScreen and RegistrationScreen render forms from immutable SessionViewModel state. SessionNavigation owns separate authentication/protected graphs; HomeScreen and PreviewLessonsScreen render authenticated API data. SessionRepository handles refresh/logout and maps DTOs into domain models. Password validation uses domain/model/AuthValidation; confirmation remains client-side. No Google flows, Scene Engine, completion, EXP or SRS are implemented. See docs/authentication.md and docs/android-usb-development.md.
